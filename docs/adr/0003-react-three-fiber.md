# React Three Fiber en lugar de Three.js puro

El autor tiene 6 años de experiencia en frontend con React. La mayor parte del trabajo, aparte de la nube, es interfaz (contador, ficha del gol, estado post-1000), y R3F + drei resuelven en React los eventos de clic sobre puntos y las capas HTML. Stack: Vite + React + React Three Fiber + drei, con despliegue estático.
